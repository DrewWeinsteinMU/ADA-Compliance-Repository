Uses WCAG 2.2 contrast guidance (4.5:1 ordinary text; 3:1 large text). Automatic formatting cannot certify ADA or full WCAG compliance. The review checklist includes all 86 WCAG 2.2 criteria, with A/AA baseline checks and AAA guidance. Items that are not automatically tested require applicability and human review. Review image descriptions, table structure, heading levels, and reading order, then run Word’s Accessibility Checker. The original file is unchanged. Word uploads can be exported as tagged PDFs. PDF uploads are reconstructed from extracted text; their visual layout, images, and table relationships are not retained. This app does not run OCR. Check the source for content extraction missed.
Files are processed by this app without external document services. Download copies are held temporarily in server memory, expire after 30 minutes, and may expire earlier when the app is busy.
